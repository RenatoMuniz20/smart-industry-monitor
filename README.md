# smart-industry-monitor
Projeto final da disciplina de Sistemas Distribuídos

## Dataset Replayer

O [Dataset Replayer](dataset-replayer/README.md) é o componente em C que fornece
a entrada de dados históricos na arquitetura do Smart Industry Monitor.
Nesta etapa, lê e valida o CSV linha a linha, seleciona registros por máquina
e os imprime no terminal. A integração MQTT será desenvolvida posteriormente.
